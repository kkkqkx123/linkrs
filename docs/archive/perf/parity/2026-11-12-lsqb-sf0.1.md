# 三引擎对比：LSQB-sf0.1（2026-11-12，devs）

**阶段**: 7.4 阶段 1 —— LSQB-sf0.1 三方 COUNT 对齐（正确性优先）。
**方法**: `docs/tests/benches/devs_lbug_neug_parity_design.md` §7。

## 环境块

| 项 | 值 |
|----|----|
| 机器 | devs（Ubuntu 18.04.5，内核 4.15，2×E5-2667 v3 32C，AVX2） |
| linkrs | git `f5c2d699`（devs repo BUILD_INFO，binary 预编译于该次同步） |
| ladybug | wheel `ladybug==0.22.3`（PyPI，`import ladybug`，垫片回退） |
| neug | wheel `neug==0.3.1`（PyPI） |
| CPU 亲和 | Python 侧未绑核（后续轮次统一 numactl+taskset node1）；linkrs `taskset -c 16-31 numactl --membind=1` |
| 线程数 | 三方一致 `threads=8`（neug AP 单线程实现，见口径注记） |
| 频率策略 | 全核 `powersave`（不可调，最大误差源；同核集中位数口径） |
| io_uring | 无（内核 4.15），存储层解读需注明 |
| 计时口径 | linkrs/lbug 内计时去 max 平均；neug 外部 wall-clock 全物化（`perf_counter`） |

## 正确性门

LSQB-sf0.1 九条 COUNT **三方整数全部相等**（1700 / 215488 / 172438 / 18135 / 215488 / 172438 / 107461 / 108027 / 172438），无 skip 查询。

## 口径注记

1. **neug AP 单线程**：`max_thread_num` 仅约束 TP 槽位，neug 数字按单线程解读，不与 linkrs/lbug 比加速比。
2. **neug 计时为 wall-clock**（含物化），linkrs/lbug 为内计时，跨列解读需带口径差。
3. **linkrs 简单 COUNT 显著慢**（q2/q5–q9 秒级 vs lbug 亚毫秒）：初步指向 count 聚合未走免物化快捷路径/边扫描全量物化，属优化信号而非口径问题，建议单独立项排查。
4. lbug 侧 vendored runner（`benchmark_runner.py`）因 vendored 布局缺上游 `CMakeLists.txt` 不可直接运行，本表 ladybug 数字来自 `neug_runner.py --engine ladybug`（同口径重实现）；vendored runner 的版本读取已回退 wheel 版本（`graphdb-ben` commit `e216518`）。

## 复现

```bash
# devs 上
source /data/kkkqkx/graphdb-ben/bench-env.sh
# linkrs
cd /data/kkkqkx/linkrs/repo && ./target/release/linkrs-parity-bench copy \
  --dataset lsqb-sf0.1 \
  --csv-dir /data/kkkqkx/graphdb-ben/data/social-network-sf0.1-projected-fk \
  --script benches/parity/schema/lsqb.cypher --db /tmp/linkrs-parity/lsqb-sf0.1/db
./target/release/linkrs-parity-bench run --db /tmp/linkrs-parity/lsqb-sf0.1/db \
  --space lsqb --benchmark-dir benches/parity/queries/lsqb \
  --warmup 1 --run 3 --threads 8 --out /tmp/linkrs-parity/results/lsqb-sf0.1-t8
# lbug / neug
python /data/kkkqkx/graphdb-ben/neug_runner.py --engine ladybug \
  --queries /data/kkkqkx/linkrs/repo/benches/parity/queries/lsqb \
  --out /data/kkkqkx/graphdb-ben/results/lbug-lsqb-sf0.1.json --threads 8
python /data/kkkqkx/graphdb-ben/neug_runner.py --engine neug \
  --queries /data/kkkqkx/linkrs/repo/benches/parity/queries/lsqb \
  --out /data/kkkqkx/graphdb-ben/results/neug-lsqb-sf0.1.json --threads 8
```
