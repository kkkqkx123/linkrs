# 查询逻辑树与物理树改进方案

本文分析 `crates/linkrs-query` 内逻辑树与物理树的现状，给出问题清单与修改方案。范围覆盖规划层的逻辑节点枚举与物理节点枚举、逻辑到物理的正向转换与反向桥接、优化器内的双路径代价决策、执行计划载体与流式 arena 构建。绑定器与流水线缓存问题见问题目录与绑定规划整改方案，本文不再重复。

语言约定为文档使用中文，代码与注释保持英文，不在代码注释中引用本文的章节编号。

## 现状概述

逻辑事实源为逻辑节点枚举，只表达语义，不含索引扫描与连接算法等物理选择，是优化器与物理转换的输入基准。语句规划器对查询语句产出逻辑树与物理树的双树出口，管理与系统等语句只产出物理树。执行计划载体同时持有物理根、逻辑镜像、行估计映射、连接算法映射、分区规格与诊断记录。优化器先补齐逻辑镜像，再分别走逻辑路径或物理路径做代价决策，最后做物理映射合并与分区选择。流式执行侧的 arena 构建器把物理树装配为算子规格向量与分片图，再物化为拉模型执行器。

该分层意图清晰，但中间多出一层规划者物理树，导致同一语义存在三种表示，同一决策存在两套实现，同一冲突存在多处兜底。

## 问题清单

逻辑与物理表示三重化。逻辑枚举约六十变体，物理枚举约八十变体，arena 装配约九十变体。逻辑到物理一遍全量转换，物理到逻辑一遍按需桥接，物理到 arena 又一遍装配转换。三处匹配分支需同步演进，新增算子至少要改两处，遗漏即表现为某条路径的扁平执行或装配失败。

执行计划载体职责过重。同一结构体同时承载计划树、优化中间态、执行配置与展示诊断。行估计与连接算法以外挂映射存放，以节点标识为键，而物理映射与启发式重写会重建节点并产生新标识，映射的时序正确性依赖最后统一重采来挽救。分区规格、并行度、背压、回退原因与代价记录混在一起，缓存指纹与物理构建各取所需，阅读与测试都要加载全部字段。

代价决策双轨重复。优化器按有无逻辑镜像分发为逻辑路径与物理路径。连接排序、索引选择、排序转 TopN、聚合策略、子查询解嵌套、子节点遍历、行估计在代价目录下各有逻辑版与物理版两套实现。逻辑版改完逻辑树后，还要顺带重写物理根并回写算法映射，两处逻辑必须同改同测。逻辑树的频繁整树克隆也增加了不必要的开销。

物理提示合并脆弱。索引提示先按子节点序号路径收集，再在转换后的物理树上按路径下沉覆盖。路径依赖转换前后子节点顺序一一对应，形态稍有分歧即跳过。合并阶段对因子化算子恒保留，对索引扫描与 TopN 按胜负规则覆盖，其余按枚举判别式与子节点数量比较，分歧时保留物理子树并记一条诊断。该机制用诊断记录代替结构保证，冲突原因难定位，触发条件目前仅覆盖因子化与三类带提示扫描， TopN 与连接决策依赖合并的隐式行为。

反向桥接存在豁免集。直接控制流中的递归公共表与存档点、全部参数化管理节点、统计展示与系统调用等十余变体无逻辑镜像，桥接时明确豁免并保持扁平执行。这类语句天然跳过因子化与逻辑路径代价决策，分区与行估计也只能走物理侧的有限能力。豁免本身是合理设计，但豁免清单的维护靠约定，新算子容易误入默认分支。

非对称语义靠哨兵维系。逻辑跳过在物理侧无对应变体，正向用极限值限制表达跳过，反向再按极限值识别回跳过。索引扫描在正向由提示生成，反向降级桥接为带提示的全量扫描。聚合在缺少分组键表达式时桥接失败。这三处都是正确性敏感点，目前靠注释与测试维系，没有类型级保证。

装配侧写路径分发过粗。来源、一元、阻塞、图、递归分片等按执行职责分发清晰，但约四十种写与管理及系统及检索及事务节点共用同一写分支入口，职责边界只在子模块内体现，顶层装配的可读性与分区安全判断成本偏高。

## 修改方案

总体约束为只修改原模块，不建替代模块，不做兼容层，不保留已知死代码。拆分只按职责拆分，不按新旧拆分。名称描述模块功能，不描述比较关系。近期只做原模块内局部修改，中期做跨模块的职责收敛，远期结构选择需另行立项，立项前维持现状。

### 近期治理：消除静默兜底与哨兵

物理提示合并的分歧处理改为显式失败优先。保留因子化算子恒保留的语义不变，其余判别式不一致或子节点数量不一致时，不再以保留物理子树加诊断收场，而是向优化器返回可定位的错误，注明两侧算子名与分歧位置。调用方按语句类型决定是失败还是降级，降级必须显式声明，不得在合并函数内部消化。该修改只动物理映射器原文件与优化器引擎的调用点。

跳过语义取消哨兵值。逻辑与物理统一为同一种偏移分页表达，物理限制节点直接承载偏移与数量，解释层负责展示形态。删除以最大整数表达跳过的双向识别分支，相关正反向转换各删一处特判。该修改只动逻辑枚举、物理限制节点与正反向转换的分页分支。

索引提示携带方式由事后覆盖改为随行转换。扫描转换函数在见到带提示的逻辑扫描时直接生成索引扫描，不再先收集路径再下沉。路径收集与下沉函数在迁移完成后删除，物理映射器的对外入口保持不变。该修改只动物理映射器与物理规划器的扫描分支。

反向桥接的豁免清单改为显式登记。管理与系统及直接控制流节点的豁免保留，但每个豁免变体必须在转换总线的豁免分支中逐一列出，不允许落入通配分支。聚合缺少分组键表达式的失败保留显式错误，不得伪造表达式标识。该修改只动反向桥接总线与其测试。

### 中期重构：收敛双轨决策与外挂状态

代价决策按职责收敛，不再按逻辑物理分文件。连接排序、索引选择、排序转 TopN、聚合策略、子查询解嵌套的成对实现，收敛为同一决策核心加两种节点访问适配。遍历骨架只保留一套，逻辑树与物理树的差异收在子节点读写适配层。优化器的逻辑路径成为唯一决策源，物理独占语句显式标记为非优化语句并跳过，而不是走另一套重写。该修改分别在各代价子目录原文件内完成，不新建统一决策模块。

行估计与连接算法由外挂映射改为随节点携带。估计行数复用扫描与过滤等节点已有的估计字段，连接算法复用连接节点已有的算法建议字段，装配器直接读取节点内决策，不再以标识查表。执行计划载体中的两个映射在迁移完成后删除，缓存指纹与物理构建的参数传递随之简化。该修改动计划节点定义、代价回写点与 arena 构建器的读取点，均在原文件内进行。

执行计划载体按职责拆分展示信息。计划树与逻辑镜像保留在载体内，分区规格与并行配置保留在载体内，代价记录与回退原因收拢为同一诊断记录结构并随计划搬运，不再散落为多个字符串与向量字段。该拆分在原文件内以职责分组完成，不抽新文件，不改公共构造函数的调用语义。

装配写分支按执行职责细分。插入删除与拷贝、数据定义管理、统计与系统调用、全文与向量检索、事务控制在装配入口处分派到各自子装配器，与来源一元阻塞等分支平级。该修改只动装配转换原文件的分支划分，子装配器实现不动。

### 远期演进：评估中间物理树的去留

中间物理树是否可消，需立项后评估。理想终态为语句规划器只产出逻辑树，优化器只改逻辑树，arena 构建器直读逻辑树加物理决策表，物理枚举不再作为中间载体。该工作涉及全部语句规划器出口与全部装配分支，风险高，本文只给出评估项，不直接开工。评估项为逻辑镜像补齐成本、物理独占语句的分类去留、 arena 直读逻辑树的改动面、计划缓存键是否需要随之调整。未立项前维持双树双轨，仅执行近期与中期方案。

## 实施顺序

先完成近期治理并通过查询包编译与格式检查，再启动中期重构。近期每项独立可验证，合并为少量编译批次。中期按代价子目录逐个收敛，每收敛一对实现即运行对应单测，避免跨目录大爆炸。远期评估在中期验收后另行立项，立项前不做结构变更。

## 验收标准

近期验收为合并分歧不再出现保留物理子树的静默记录，全部冲突以错误定位到算子名；分页不再出现极限值哨兵，正反向各只有一种表达；索引提示无路径收集代码，带提示扫描一次转换到位；反向桥接无通配兜底，新增变体遗漏时编译或测试失败而非扁平执行。

中期验收为每组代价决策只有一套决策核心，逻辑与物理差异只在访问适配层；执行计划载体不再以外挂映射传递行估计与连接算法，装配器只读节点内字段；诊断记录结构统一，解释输出内容不变；装配写分支入口按职责分派，行为测试全过。

远期验收为输出评估结论，明确中间物理树保留或消除的决策与改动面估计，在立项前不改生产结构。

## 实施进展

近期治理已全部完成并通过查询包全量单测。物理提示合并的分歧处理改为显式错误，错误携带两侧算子名与树路径，优化器遇到分歧直接返回计划优化错误。跳过语义的哨兵值收敛到限制节点的单一命名常量，正反向转换与 arena 限制规格均经由该常量识别，偏移分页不再散落魔法数字。索引提示改为转换期随行生成，路径收集与下沉覆盖代码已删除，邻接扩展的无效提示触发条件一并移除。反向桥接经核查已为穷举匹配，无通配分支，聚合缺分组键表达式保留显式错误，未做结构变更。

中期重构已完成决策收敛三组与装配细分一组。排序转 TopN 的物理与逻辑两版统一到同一代价检查核心，附带修复无界限制的溢出风险。索引选择的物理重写与逻辑标记统一到同一决策核心，目录内重复的说明注释合并为一处。聚合策略的物理与逻辑两版统一到同一说明构造核心。装配写分支按数据修改、模式管理、检索、事务、控制五组职责拆分为独立方法，顶层路由随之分组，全量单测通过。

剩余中期工作为连接排序、子查询解嵌套、行估计三组决策收敛，以及行估计与连接算法入库、诊断记录结构统一，均遵循上文已验证的同一模式：决策核心下沉到原模块，调用方只保留形态适配。远期中间物理树去留评估尚未立项，维持现状。
