# 独立分析任务：写路径 commit gate 扩展性

来源：docs/issue/commit-gate-write-scaling-collapse.md。
性质：架构决策型任务，本轮仅修复 bench 结论文案计算，不动 gate 本体。

## 已知事实

高频小语句竞争下 gate 等待占比随线程数单调上升，16 线程总吞吐远低于单线程；批提交路径本身不慢，瓶颈集中在 gate 串行化；bench 文案为写死字符串，与实测值矛盾。

## 待确认事项

临界区归属与持锁粒度；按键哈希分片 gate 的正确性边界；无锁 staging 提交的可行性；cgroup 配额对绝对数值的影响，需真机复核后更新容量契约。

## 决策后实施方向

经评审后实施分片或重构，并更新容量文档；bench 文案修复先行，不代表扩展性问题已解决。

## 验收口径

多线程 gate 等待占比显著下降；容量契约文档与真机数据一致。
