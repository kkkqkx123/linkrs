# 独立分析任务：单批 1M 顶点持久化挂死

来源：docs/issue/ingest-1m-wal-hang.md，严重级最高。
性质：定位型任务，本轮不改代码，待复现抓栈明确后再转实施。

## 已知事实

单批 1M 顶点经持久化路径挂死，WAL 文件停在约 66.8MiB 量级后零增长，线程全部 futex 等待且 CPU 冻结；同等数据量按 100k 分块可成功装载；10k 与 100k 批外推应为秒级。

## 待确认事项

WAL 段边界轮转是否等待被批插入持有的锁；组提交协调是否存在背压死锁；checkpoint 是否参与互相等待。需在开发板用 debug 构建与完整回溯复跑确认挂死点。

## 决策后实施方向

定位后修协调语义；bench 侧增加超时看门狗便于回归捕获；文档中给出调用方分块上限建议仅作为临时规避，不作为最终修复。

## 验收口径

1M 单批可在有界时间内完成或给出明确错误；WAL 增长单调；不再出现零 CPU 永久等待。
