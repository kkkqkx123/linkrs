# 独立分析任务：HNSW 分配 churn 优化

来源：docs/issue/hnsw-alloc-churn.md。
性质：热路径重构任务，本轮不改代码，待方案评审后实施。

## 已知事实

万点构建分配近 2GB，过滤搜索 miss 路径分配数百 MB；热路径每次搜索层调用新建哈希集合与二元堆；构建耗时与分配器压力显著。

## 待确认事项

每线程暂存复用的生命周期归属；访问模式递增槽位下位图或世代标记数组替代哈希集合的正确性；堆与候选缓冲复用的内存上界；并发场景下分配器锁影响的量化。

## 决策后实施方向

引入可复用暂存，替换访问集合实现，复用堆缓冲；以分配统计基准验证数量级下降。

## 验收口径

构建阶段分配字节数下降一个数量级；过滤搜索耗时显著回落；内存峰值下降。
