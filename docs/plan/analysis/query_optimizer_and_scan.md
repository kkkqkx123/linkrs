# 独立分析任务：查询基数估计与扫描吞吐

来源：docs/issue/query-plan-estimation-and-scan.md，关联 OLAP 最慢查询。
性质：优化器与执行层设计任务，本轮不改代码。

## 已知事实

过滤选择性默认显著偏离实际；两跳展开估计双向偏差可达数量级；顶点全扫描吞吐比边扫描低约两个数量级，与逐行物化 Value 的既有判断一致。

## 待确认事项

列统计接入过滤选择性的覆盖范围；出度统计接入展开估计的方式；顶点扫描列式化与边扫描调用者缓冲模式对齐的范围；聚合 TopN 受益的量化。

## 决策后实施方向

估计器先接已有统计信息，扫描侧做批量解码向量化；重跑遍历与 OLAP 基准验证。

## 验收口径

估计偏差收敛到可用区间；顶点扫描吞吐显著提升；端到端两跳与 OLAP 查询耗时下降。
