# 独立分析任务：bench 基建与契约决策合集

来源：docs/issue 中 bench-pk-mirror-fails 的契约讨论、tantivy-bench-infra 的工具链项、fulltext 默认特性建议、observational-notes 全部观察项。
性质：决策合集，本轮不实施，需集中拍板后再转各实施项。

## 事项一：主键镜像契约语义

bench 修数据生成只是止血。若业务需要自然键，该约束是否过强需产品与存储共同决策；错误信息是否需要同时给出顶点 id 与期望规则也在此决策。

## 事项二：jitexpr 工具链

可选依赖拖入 workspace 解析并要求更高编译器版本。候选：锁定兼容版本、移出默认 workspace 成员、升级工具链。三者影响构建与发布，需统一决策。

## 事项三：fulltext 默认特性

bench 占位静默问题本轮以提示语缓解；是否将 fulltext 纳入默认特性涉及默认构建体积与依赖，需决策。

## 事项四：bench 运行效率

大规模 bench 默认采样耗时达小时级；是否引入 QUICK 环境变量约定、标注长 bench 预期时长、统一各包 bench 入口行为，需决策。

## 事项五：观测项真机复核

并发搜索回退、WAL 同步策略差异、CSR 宽行 miss 路径、冻结回收计数语义等均受限于受限配额环境，需在开发板或真机复核后决定是否建正式优化项。

## 验收口径

每事项有明确结论与对应实施清单；bench 全绿门禁与运行约定文档化。
