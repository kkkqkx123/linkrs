# 绑定器与规划器整改方案

本文给出绑定器与规划器问题的分阶段修改方案，是问题清单的后续行动指南。问题明细见同级问题目录。

## 目标与约束

目标为消除正确性隐患与局部重复，为完整重构准备干净起点。约束为修改现有模块自身，不引入替代模块，不新增兼容层，不保留已知死代码。文档中不展开完整实现细节，仅说明职责归属与验收标准。

## 近期治理

近期治理只做局部修改，不改变架构分层，全部在原模块内完成，便于单次编译验证。

绑定侧近期内容为统一表达式遍历覆盖、抽取投影与排序公共绑定逻辑、删除函数名单重复分支、统一属性类型解析的作用域部分、统一错误构造器入口。验收标准为返回与产出子句共享同一绑定路径，变量存在性检查覆盖子查询与属性变体，错误文案经由统一入口。

规划侧近期内容为删除连接器死代码并切换其唯一测试到计划组合器、删除无人消费的模板抽取器并移除重导出、收敛合取项拆分到扫描谓词作为唯一来源、统一解包等规划器的物理出口到逻辑根封装。验收标准为生产代码无空连接键构造，模板化只剩形状归一化与缓存键两套有意分离，合取项拆分只有一处实现。

## 中期重构

中期重构处理结构性重复，需要跨模块协调，安排在近期治理验证通过之后。

绑定侧中期内容为清理遗留验证结构与逆向桥接，使规划器只消费已决议中间表示，按职责拆分数据定义绑定文件，合并返回与产出子句结构体。规划侧中期内容为统一索引信息与代价模型类型入口并明确各自适用范围，收敛递归规划到统一路由表，统一语句与子句规划器的出口契约。

## 远期演进

远期演进处理双树与缓存等架构选择，立项前需单独评估。

内容为评估逻辑物理双树是否收敛为单树，统一计划缓存键与备忘键的构造与失效说明，明确扩展点的去留。物理独占算子的逻辑镜像缺失、聚合反向桥接的信息丢失、连接排序两阶段分工均在此阶段决策。未立项前维持现状，仅做文档说明。

细化设计与明确决策见同目录《查询远期工作细化设计》。

### 远期决策说明（未立项，维持现状）

双树维持双轨运行：双树出口已收敛为单一构造入口，后续收敛为单树时只需迁移该入口的调用方，无需再逐处查找拼装点，在此之前不做结构变更。

缓存键与备忘键维持两级设计：写路径备忘跳过绑定，读路径计划复用，两者构造点已在流水线与编译器各自收敛，统一为单一键构造说明的工作随缓存失效语义梳理一并立项。

扩展点维持实验性预留：四类扩展点已有接线但无生产实现，不做删除也不做推广，规划器不得依赖扩展点做兼容，后续去留单独决策。

匹配规划仍从抽象语法树取模式：绑定消费已完成验证信息线程的清理，但模式规划的语法树输入属于重写级工作，随单树评估一并立项，在此之前保持现状并以已决议删除子句与变量集合为边界约束。

## 实施顺序

先完成近期治理并更新文档，再启动中期重构。近期治理合并为少量编译验证批次，避免频繁编译。完整重构不在本文展开，待近期治理验收后另行立项。

## 近期治理完成情况

近期治理已全部在原模块内完成，不涉及架构分层变更。

绑定侧已完成变量存在性检查对子查询与属性变体的覆盖，返回与产出子句已共享同一投影与排序绑定路径，函数名单重复分支已删除，属性类型解析的作用域部分已统一到表达式绑定器，错误构造已统一到绑定器错误入口。解包独立变量辅助逻辑保持原行为，仅做路径复用。

规划侧已删除连接器模块并移除重导出，其唯一测试已切换到计划组合器的交叉连接路径。模板抽取器模块与重导出已删除，模板化只保留形状归一化与缓存键两套有意分离。合取项拆分已收敛到扫描谓词作为唯一来源，连接键抽取与冗余标签过滤已复用该实现。解包规划器已统一到逻辑根封装出口。

验证情况为查询包编译检查通过，格式检查通过。测试编译检查通过。完整单测因机器资源限制未全量运行，留待中期重构前补齐。中期重构与远期演进范围不变，直接基于当前干净起点立项。

## 中期重构完成情况

中期重构已完成，仍在原模块内收敛，未引入替代模块与兼容层。

绑定侧已清理遗留验证结构在规划层的读取：规划上下文不再携带验证信息，变量存在性改由已决议查询图直接提供，解包、分组、存在性子查询等规划器不再合成空验证包装。数据定义绑定文件已按职责拆分，事务控制、诊断包装、管道子句、脚本赋值各归其位。返回与产出子句结构体已合并为单一投影子句类型，历史别名全部删除，采样子句的静默丢失一并修复。

规划侧已统一索引信息与代价模型类型入口：无统计量索引代价收敛到代价配置的单一方法，两处私有复刻已删除，各模型适用范围在模块文档中明确。递归规划已收敛到统一路由表的两个入口，管道、集合、解释、赋值、公共表表达式均复用同一分发。语句与子句规划器的出口契约为单一双树构造入口，生产代码不再直接拼装计划结构。

验证情况为查询包编译检查通过，格式检查通过，绑定器与规划器相关单测通过。远期演进范围不变，决策说明见下节。
