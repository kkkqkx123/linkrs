# 顶点清理剩余任务清单

交接基线为当前工作树。早期的暂停交接描述已过时，外层生产代码与大部分测试实际已经提交，本清单只记录代码现状中仍未闭环的事项。全文只用自然语言描述，不含代码片段。

## 拍板：无标签遍历一律从边 schema 派生

走向、路径、子图语句的语法不带标签，规划器也没有 schema 访问能力，因此规划层不再拦截，一律把空标签透传到执行层。执行层以边类型 schema 为唯一依据：邻居按所在边的端点侧取标签，字面种子按方向取种子侧标签，路径端点在单同构边类型下取公共标签，带标签的顶点值直接透传。凡是派生不出的 hops 一律跳过，未知边类型与歧义域直接报错。全程无猜测、无空标签伪造、无跨表探测。

## 已确认完成，无需返工

标识非受检构造器已删除，仅保留受检构造与类型化重建入口。顶点类型已收敛为单标签单属性映射，内部行号字段已删除。存储读写按标签直查直写，删除入口要求标签，跨表探测与多标签删除入口已删除。主键镜像的旧数据修复分支已删除，写入自动填充与不一致拒绝、更新禁主键保留。批量链路的服务端、嵌入式会话、C 接口、传输层、重建来源、迁移执行器、全文管理均已按单标签改写。匹配遍历的邻居标签透传骨架已贯通，管道删除与子图算子的裸标识口径已统一。

## 本次闭环事项

表达式起止节点函数不再伪造空标签顶点，纯函数路径明确报错，存储路径按边 schema 解析端点标签后读取，端点已删除时返回空。展开算子无存储回退不再伪造默认顶点，改为空值。点查源的标识解析拒绝负数落入文本种类，超长输入返回错误而非默认值。索引删除与列存边车校验的硬解包改为按契约返回错误。批量写入的按标签预留计数改名，避免被误判为多标签残留。GO 与路径规划器的永拒拦截已删除，路径规约构造器补齐构造逻辑，递归片段算子的空标签拦截改为端点物化加跳过。GO 与路径执行测试改用带端点标签的边类型固件，断言成功行数与空结果，不再锁定报错。

## 已知局限

字面端点加异构或无标签边 schema 的路径查找返回空结果，需要语法层面补充标签后才能彻底解决。字面种子加多边类型或双向异构边类型的遍历直接报错。向量与 DDL 路径的个别默认回退不在本次顶点任务范围内，留待后续专项处理。

## 验证顺序

每次只跑一个批次。先跑查询库测试编译，再跑全工作区测试编译，然后跑存储与查询回归，最后做全仓残留检索与格式化检查。
