# 冷规划、重放与并行：下一阶段设计

上一轮设计覆盖了五个方向，结论是缓存键守成、同步语义维持默认、
冷规划快路径、检查点增量基线、并行封顶三项立项。
其中快路径与并行封顶已在原模块内落地，增量基线经核查已在位。
本轮只回答下一阶段还值得做什么，所有改动继续收敛在原模块，
默认语义不变，每个方向绑定已有探针与基准作为验收门。

## 基线（沿用上一轮同机数字，不重复论证）

冷规划：快路径使冷点查优化段约三百六十五微秒到约三百一十微秒，
冷一跳约五百三十四微秒到约四百四十七微秒，约百分之十五。
画像三段耗时已接线，验收以画像分段为准。
此前验收口径数十微秒未达成，剩余主要为索引选择、
连接保留注记判定、启发式驱动固定开销与框架成本。

检查点与恢复：两千顶点四千边下干净基线 reopen 约百毫秒量级，
带尾部日志约十余倍，上一轮缺口未收敛反而拉大。
日志解析已并行，串行锁与崩溃一致性交互保持不变。
真缺口是重放应用侧的逐条插入代价。

并行：八 worker 相对四 worker 无收益或转负的结论多轮一致，
封顶机制已在单一收敛点落地并由单测锁定，分区数按设计下降。
封顶的端到端效应在本轮数据中不可分辨，
原因是三轮呈系统性漂移，对照组同样逐轮走低，
属机器环境漂移而非封顶所致，需干净窗口专用前后测。

同步语义：同步档与批量档持平，从不同步仍略慢，
保持强同步默认的判断不变，本阶段不做任何改动。

## 冷规划第二阶段：单链遍与实例复用

分段计量的实测结论：快路径剩余耗时中快启发式约占七成，
其中第二遍链遍的五个分批零规则命中，属纯校验开销；
代价侧的统计视图与代价实例在各阶段重复构造。
目标是把快路径优化段继续下探，不动索引选择语义与驱动结构。

做法收敛在原模块：链遍预算由常量改为实例可配，默认值不变，
快路径在构造时置为单遍，以快慢全对等断言为守卫；
统计视图与代价实例在快路径入口构造一次并在各阶段间共享，
解释输出与全量路径逐字可比。任何注记的增删都视为行为变更。

验收以画像优化段为准：冷点查快启发式阶段已从约三百微秒
降到约一百九十五微秒（八个样本无交叠），
快慢全对等断言全绿，单链遍以新增的边扫描语料与遍数断言锁定。
风险是单遍丢失跨分批的二次改写机会，
以覆盖门控语法的等价语料锁定，超出语料的形状走全量路径不受影响。

## 重放应用侧：先分段计时，后批量应用

目标是把尾部日志与干净基线的倍数关系收敛，
但批量重放属于高风险后续项，本阶段分两步走，
第一步只加观测，不动行为。

第一步在原恢复模块内加分段计时：
日志解析、一致性过滤、基线恢复、应用重放各记一段，
输出接到崩溃恢复基准的一次性报告中。
本步无行为变更，验收门是两场景退出码全绿且分段数字稳定可读。

实测修正：两千顶点四千边下尾部重放三千条目中解析约三毫秒、
过滤与恢复为零、应用约十五毫秒，而一次性墙钟约一千八百八十毫秒。
应用侧不是缺口驱动项，批量应用的前提不成立，延期。
剩余约一千七百五十毫秒落在恢复管理器之外的收尾段
（延迟边排空与恢复末全量检查点在机械盘上的落盘），
下一步先给收尾段加同口径分段计时，再决定动向。

第二步才是批量应用，当前仅立项不落地：
同一日志段内按表分组连续插入，每组只持一次表锁，
索引更新推迟到组末，串行锁、持久化位点与幂等语义保持不变，
重复插入与良性缺失的判定口径不变。
调用方式参考批量会话先例，走显式会话或配置门，
默认路径保持逐条。本项当前冻结：分段证据已证明应用侧
不是主导段，解冻条件是收尾段计时证明瓶颈回落到应用侧。
验收以恢复与存储基准为准，崩溃恢复两场景全绿为硬门，
另加事务隔离与日志恢复套件全绿。

## 并行：干净窗口验收与可观测，不动算子

封顶代码已落地，本阶段不做任何算子与阈值改动。
只做两件事：一次干净窗口的专用前后测，
以及把已有效果显式化为可观测口径。

专用前后测与日常基准分离：同提交、安静窗口、
固定数据集与轮数，以不受封顶影响的边扫描为对照组。
若对照组同样漂移则判定为环境问题，本轮数据作废重跑，
不再把漂移误读为封顶效应。报告同时记录请求分区数与
实际分区数，以及经济上限的回退原因，使后续调参有据可查。
这些口径复用分区决策已有的原因字符串，
只做透出，不新增决策逻辑。

验收以并行扩展基准为准：
此前变慢的查询在高 worker 下不慢于串行，已有加速比保持；
对照组稳定是本轮数据有效的前提。
无正确性风险。

## 明确不做

缓存键结构继续守成，只在出现误命中或误 miss 时按维度加计数定位。
默认同步语义不变，任何跳过同步的路径必须由调用方显式传入。
窄布局、向量方向、全文增量写法、回滚分片维持不投入。
检查点建立与老化上限机制已在位，本阶段不动。

## 验收汇总

冷规划以画像优化段与快慢全对等断言为门；
重放第一步以分段计时落地与两场景全绿为门，
第二步以分段证据为启动条件；
并行以干净窗口前后测与对照组稳定为门。
所有验证在安静窗口重跑，沿用现有基准二进制调用方式。
