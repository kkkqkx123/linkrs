# GPUI 客户端 OS 凭据存储设计方案

> 对应《剩余工作细化方案》长期延期的 keyring 项。现状基线：密码永不落盘，会话 id 只驻内存。

## 1. 目标与非目标

目标：用户显式勾选时，把登录密码存入操作系统凭据存储，下次打开登录页自动预填，一键连接。默认不勾选，行为与今日完全一致。

非目标：会话 id 继续只驻内存，不进 keychain 也不进配置文件。它是短期 bearer token，有过期语义，重启后用已记住的密码重登即可达到同等体验，持久化 token 只会扩大攻击面。同样不做启动静默自动连接，只做预填加用户确认点击。

## 2. 依赖选型

采用 `keyring` 3 系作为跨平台抽象，只改桌面客户端自身 workspace 的依赖与锁文件，不动根 workspace。各平台后端由特性门控：Linux 用同步 Secret Service，macOS 用 Keychain，Windows 用凭据管理器。否决直连各平台原生库的做法，那等于在客户端内重造一遍 `keyring`。否决异步 Secret Service 特性，避免与同步入口混用触发编译期互斥。

选型时发现的关键点：该 crate 默认特性在 Linux 上回落到内存模拟实现，必须显式开启上述后端特性，否则存取看似成功但重启即失。

## 3. 凭据标识设计

服务名固定为客户端标识。账户名由连接三元组规范化拼接：host 与用户名去首尾空白后与端口组合，保证同一地址端口用户唯一对应一项，不同用户与端口互不串扰。用户名保持大小写敏感，与服务端鉴权语义一致。标识构造为纯函数，可单测全覆盖，不碰任何系统存储。

## 4. 模块与接线

新增一个按职责命名的凭据单元，归属连接域，仅暴露按端点读存删三个动作。读不到（含从未存过）与系统存储不可用（无守护进程、被锁、headless）统一归一为空值加日志，绝不向上传播异常，更不回退写明文文件。存拒绝空密码。删对不存在的条目视为已达成。

登录视图新增状态：记住勾选与已知已存端点。构造时对上次连接静默起后台预填，命中则填密码框并自动勾选。最近连接点击改为先填表单再后台取密码最后走原提交链路，保留一键连接体验且无竞态。登录成功后按勾选在后台写或删：勾选且密码非空则保存，否则删除当前端点条目。登出与会话失效只清内存会话，不动 keychain。另设显式忘记入口，可在不登录的情况下清除当前端点的已存密码。

所有 keychain 调用均为同步 IPC，必须走后台执行器，永不在 UI 线程执行。后台任务失败只记日志，不阻塞登录主流程。

## 5. 安全规则

默认关闭，按端点存储，密码值永不进日志与配置文件。取消勾选即遗忘。用户改密后旧条目由下次登录重建覆盖，不做自动迁移。无守护进程环境自动退化为本次内存登录加弱提示。

## 6. 测试与验收

单测只覆盖纯标识逻辑与读写删的期望语义（不存在即空、删不存在即成功、空密码拒绝存），不触碰真实系统存储。手工矩阵覆盖 Linux 有无 Secret Service 守护进程、macOS、Windows：记住、预填、取消遗忘、改密后重建、无守护进程下登录不受阻。校验收敛为桌面客户端 workspace 的一次检查加一次测试。

## 7. 后续事项

用户管理页的改密与重置密码成功后，可顺手清除对应端点条目，避免旧密码残留，单独小任务，不在本方案内。
