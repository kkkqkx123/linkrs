# 全局编号扩位初步设计（后续参考，短期不实现）

## 现状

全局内部编号由分片号与片内编号经位运算合成编解码，无需映射表。最大分片数与固定槽位宽度共同封顶单标签规模。在线扩容与渐进迁移均无承载路径，布局变更只能离线重建。

## 目标与非目标

目标是解除单标签规模上限，支撑更大分片数与更深片内容量。非目标是不改变外部键路由的分布语义，不引入常态化间接映射表，不扩展为分布式编号。

## 设计方向

优先在编号中预留代际位与容量预留位，使新旧编号可按代解码，老数据重建时一次性翻译。位宽扩展与分片上限提升同步评估，避免分两次重建。边表端点引用随顶点映射一次性翻译，翻译完整性沿用重分片的预检与拷后对照思路。清单固化新布局的位宽与路由版本，旧布局拒绝直接打开，必须走重建。新建表按预估规模选择布局的规则保持，扩位后仅调整阈值而不改变规则形状。

## 关键取舍

定长可解码编号保持点查与边解析的高效，代价是位宽变更必须全量重建。间接映射表可避免重建，但会给每次边解析增加一次查表，不符合单机轻量定位，因此不采用。

## 风险

位宽变更是全库级联变更，顶点、边、索引、检查点必须同代切换，错一代即误解码。边翻译映射的完整性证明是主要成本，缺失一条即产生悬挂边。持久格式版本必须严格拒绝混代打开。

## 推进顺序

先冻结编号位分配与代际解码规则并补齐拒绝语义，再做离线扩位重建与边翻译，最后才考虑与在线重分片的组合。扩位与在线重分片宜合并评估，分开立项但共享编号语义评审。
