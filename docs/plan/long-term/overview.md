# 长期方向总览（后续参考，短期不立项）

本文收敛六个明确不做的长期方向，给出各自一句话定位与建议顺序，供后续按需立项。所有方向均保持单机轻量定位，改动作用于现有模块，不引入替代存储引擎与索引类型，老数据以重建为准。

## 方向一览

* 磁盘分级主键索引：将主键索引内存上限转为磁盘容量上限，点查尾延迟换内存上限。
* 在线重分片：在离线重建与干跑预检基础上，支持在线扩容与渐进迁移。
* 全局编号扩位：在分片数与槽位宽度封顶消除后，扩展单标签规模上限。
* 复合主键：将主键从单列整数与文本扩展为多列组合键。
* 通用二级索引：在主键点查与区域剪枝之外，提供按列的条件加速。
* 版本链跨重启持久：将值级历史从纯内存扩展为跨重启可用。

## 依赖与建议顺序

磁盘分级与版本链持久相互独立，可并行调研。全局编号扩位是在线重分片的前置约束澄清，两者宜合并评估，避免编号语义反复变更。复合主键宜先于通用二级索引，因为二级索引的键规范化与校验可复用主键的形状规则。版本链持久宜放在磁盘分级之后，因为两者都要回答增量落盘与回收协同问题，后做可复用前者的合并与检查点经验。

## 统一约束

提交清单仍为唯一提交点，快照读语义不弱化，可观测性字段随功能补齐。统计口径保持近似求和并在文档中写明。任何方向立项前，先补齐干跑预检与回退路径，再进入数据拷贝与格式变更。
