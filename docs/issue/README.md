# 查询绑定器与规划器问题清单总览

本文是绑定器与规划器治理的唯一问题入口，汇总当前已确认的全部问题。分项明细见同目录其余文档。

## 范围

仅覆盖 `crates/linkrs-query` 内的绑定、规划及与其直接交互的流水线、优化器、缓存、扩展点。执行器、存储、网络层问题不在本文范围。

## 问题分项

绑定侧共十项，明细见绑定器问题清单文档。核心是三层语义检查重叠、双表达式遍历器并存、投影子句绑定逻辑逐行重复、属性类型解析双实现、变量存在性检查存在漏检分支、错误构造器未统一、遗留验证结构仍被读取。

规划侧共四组，明细见规划器问题清单文档。核心是连接器死代码且连接键为空、模板抽取器与形状归一化及计划缓存键三套模板化并存、合取项拆分三处重复、索引选择与代价模型四套并存、语句与子句规划器双份实现但出口不一致、递归规划存在两级分发。

交互侧共三组，明细见流水线与缓存交互问题文档。核心是绑定到规划再到执行的调用链分散在多个流水线子模块、优化器与规划器各持一套连接排序决策、缓存键与备忘键构造分散、扩展点已接线但无生产实现。

## 近期治理状态

近期治理已完成，全部为原模块内的局部修改。绑定侧完成了遍历覆盖补齐、投影排序路径合并、名单重复删除、属性解析统一与错误入口统一。规划侧完成了连接器删除与测试切换、模板抽取器删除、合取项拆分收敛与解包出口统一。剩余结构性问题仍在中期重构与远期演进范围内，见计划目录整改方案文档。

## 严重程度说明

 correctness 风险最高的为变量存在性漏检、空连接键死代码、模板抽取器无人消费三项，已纳入近期治理。结构性重复如双套连接排序、双套逻辑物理节点体系、四套索引代价模型纳入中期重构。缓存统一、扩展点去留、遗留验证结构清理纳入中远期演进。
