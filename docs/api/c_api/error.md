# C API 错误处理

源码：`crates/linkrs-api/src/embedded/c_api/error.rs`。

## 主码

| 函数 | 说明 |
|---|---|
| `linkrs_errcode(db)` | 取库句柄记录的最近主码，无错误返回 `LINKRS_OK` |
| `linkrs_errmsg(msg, len)` | 取线程本地最近错误文本，写入调用方缓冲，返回实际写入字符数（不含结尾零，超长截断） |
| `linkrs_errstr(code)` | 主码转静态描述字符串，无需释放 |

错误文本槽线程安全；`execute` 类失败的诊断以该槽为准。

## 会话级扩展信息

| 函数 | 说明 |
|---|---|
| `linkrs_extended_errcode(session)` | 扩展码，无错误或非法会话返回 `LINKRS_EXTENDED_NONE(0)` |
| `linkrs_error_offset(session)` | SQL 错误字符偏移，无错误或非法会话返回 -1 |

扩展码分段：`1000` 语法、`1100` 求值（含类型失配、除零、越界）、
`1200` 约束（含重复键、外键、非空、唯一、检查）、`1300` 事务
（含连接丢失、死锁、锁超时、冲突、非 owner、已完成、需恢复）、
`1400` 图语义（非法点/边、路径未找到）、`1500` 内部。

## 各绑定映射口径

主码决定异常大类（忙、只读、未找到、模式、约束、类型失配、误用七组具名，
其余归入基类并保留数字码），扩展码与错误位置作为异常属性保留，
五端划分一致。详见[绑定总览](../bindings/README.md)。
